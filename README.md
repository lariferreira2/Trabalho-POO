# Trabalho-POO
<h2>Sistema de academia</h2>
<h6>Nosso projeto consiste no desenvolvimento de um sistema de gerenciamento de uma academia, com o objetivo de organizar e facilitar o controle de alunos, professores, treinos e exercícios.

O sistema permitirá realizar o cadastro, consulta, atualização e remoção dos principais dados da academia. Será possível cadastrar alunos e professores, registrar informações dos alunos, criar e organizar treinos e cadastrar os exercícios disponíveis.

O sistema será desenvolvido utilizando os conceitos fundamentais da Programação Orientada a Objetos (POO), trabalhando com classes e objetos, encapsulamento, herança e polimorfismo. A estrutura será organizada de forma que diferentes tipos de pessoas possam ser representados por classes específicas, permitindo demonstrar a reutilização e especialização de código.

Os dados do sistema serão armazenados temporariamente em estruturas como ArrayList, permitindo realizar as operações de CRUD (inserção, busca, atualização e remoção), conforme o desenvolvimento do projeto.

O objetivo final é criar uma aplicação simples e funcional que represente o gerenciamento básico de uma academia, permitindo que os usuários do sistema organizem as informações de alunos, professores, treinos e exercícios de maneira prática e estruturada.</h6>
