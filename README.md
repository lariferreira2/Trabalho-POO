# Trabalho-POO
<h2>Sistema de academia</h2>
<h6>Nosso projeto consiste no desenvolvimento de um sistema de gerenciamento de uma academia, com o objetivo de organizar e facilitar o controle de alunos, professores, planos, treinos, exercícios, avaliações físicas e pagamentos.

O sistema será composto pelas classes Pessoa, Aluno, Professor, Plano, Treino, Exercício, Avaliação e Pagamento, cada uma responsável por representar uma parte importante do funcionamento de uma academia.

A classe Pessoa será utilizada como base para representar as características comuns dos usuários do sistema. A partir dela, serão criadas as classes Aluno e Professor, utilizando o conceito de herança, permitindo reutilizar atributos e métodos comuns e adicionar características específicas para cada tipo de pessoa.

O sistema também utilizará o conceito de abstração, representando somente as características e comportamentos relevantes para o funcionamento da academia. Dessa forma, serão modelados os elementos essenciais de cada classe, evitando informações desnecessárias para o sistema.

O encapsulamento será aplicado através da proteção dos atributos das classes, utilizando modificadores de acesso adequados, principalmente atributos privados e métodos de acesso e modificação, como getters e setters. Dessa maneira, o próprio sistema poderá controlar o acesso e a alteração dos dados dos objetos.

O polimorfismo será utilizado principalmente nas classes relacionadas à herança, permitindo que métodos comuns possam apresentar comportamentos diferentes de acordo com o tipo de objeto. Dessa forma, alunos e professores poderão possuir comportamentos específicos mesmo compartilhando características da classe Pessoa.

A classe Plano será responsável por representar os planos oferecidos pela academia. A classe Treino organizará os treinos dos alunos, relacionando-os aos exercícios que deverão ser realizados. A classe Exercício armazenará informações sobre os exercícios disponíveis, como nome, grupo muscular, séries e repetições.

A classe Avaliação será utilizada para registrar as avaliações físicas realizadas pelos alunos, permitindo armazenar informações e acompanhar seu desenvolvimento. Já a classe Pagamento será responsável pelo controle dos pagamentos relacionados aos planos contratados.

O sistema também deverá realizar operações de CRUD, permitindo inserir, consultar, atualizar e remover informações. Esses dados serão armazenados em estruturas ArrayList em memória, sem utilização de banco de dados, conforme definido nas etapas do projeto.

Dessa forma, o projeto buscará desenvolver uma aplicação funcional e organizada, utilizando na prática os principais conceitos da Programação Orientada a Objetos: abstração, encapsulamento, herança e polimorfismo, além de classes, objetos, atributos, métodos e construtores.</h6>
